<h1 align="center">BloonsArchipelago</h1>

This Mod is for the [Archipelago Multiworld Randomizer](https://archipelago.gg).  It connects you to the AP server through the settings menu.

Currently in super early development, if you find any bugs please report them in the issues tab here for client issues, or in the [Bloons TD6 channel](https://discord.com/channels/731205301247803413/1465832575359516970) in the Archipelago discord.

# Requirements
1. [BTD6 Archipelago client](https://github.com/Matt41321/Archipelago/releases)
2. [melon loader](https://melon-loader.com/#getting-started)
3. [BTD6 Mod Helper](https://github.com/gurrenm3/BTD-Mod-Helper#readme)
4. [Epic Games Compat](https://github.com/GrahamKracker/BTD6EpicGamesModCompat/releases/latest) if you have the Epic Games version BTD6

# general setup
1. before setting up for modding if you dont want your ninja kiwi account being flagged for modding you may want to make a new ninja kiwi account just for modding and also copy your BTD6 folder making it easier to swap between modded and unmodded play sessions, to do this navigate to where you have the game installed. <br />
    1. <ins> **For steam** </ins> <br />
     right click the game in the game sidebar in your steam library and go to manage and then browse local files and go to the parent directory by pressing alt + up arrow <br />
     
      2. <ins> **For Epic Games** </ins> <br />
      navigate to your Epic Games folder where the game is installed likely here C:\Program Files\Epic Games
2. copy and paste your 'BloonsTD6' folder and rename it to something like 'BloonsTD6_Modded'
3. now to add that new BTD6 to steam if you want to, at the bottom of your steam library there should be a button labelled 'Add a Game' click on that and then 'add a non-Steam game' now press 'Browse' at the bottom of that window and navigate to your new modded BTD6 folder and select 'BloonsTD6.exe' press 'open' and then 'Add Selected Program'
4. now to rename the game in steam as it will always default to the name of the file, locate the game 'BloonsTD6.exe' right click it press properties and rename it in the first text-box you can also add an icon for the game here [SteamGridDB](https://www.steamgriddb.com/game/32148/icons) is a good place to find these if you want to add one <br />

# Steam Setup
1. Install Melon Loader to your Bloons TD6 install I prefer to use the installer and not the manual instalation method as it makes it easier to update melonloader in the future if needed. If you didnt make a separate modded install melon loader should automatically find your BTD6 steam install, if you made a separate modded install press 'Add Game Manually' at the bottom of the melon loader window navigate to your modded BTD6 folder and select the 'BloonsTD6.exe' choose version 0.7.3 and press install
2. Open BTD6 WITHOUT any mods installed be patient as it will take a while to load the first time
3. Open your BTD6 folder and go to the mods folder 
4. Put Both BTD6 Mod Helper and Bloons Archipelago into the Mods folder.
5. Open BTD6
7. Click the Mods Button, and hit the gear icon next to Bloons Archipelago
8. Input all your server information, and click the connect button.

# Epic Games Setup
1. 1. Install Melon Loader to your Bloons TD6 install I prefer to use the installer and not the manual instalation method as it makes it easier to update melonloader in the future if needed. If you didnt make a separate modded install melon loader may automatically find your BTD6 Epic Games install, if it didn't or if you made a separate modded BTD6 folder install press 'Add Game Manually' at the bottom of the melon loader window navigate to your modded BTD6 folder and select the 'BloonsTD6.exe' choose version 0.7.3 and press install
2. pen BTD6 WITHOUT any mods installed be patient as it will take a while to load the first time
3. Open your BTD6 folder and open mods
4. Put Both BTD6 Mod Helper and Bloons Archipelago into the Mods folder.
5. Put the Epic Games Compat into the Plugins folder.
6. Open BTD6
7. Click the Mods Button, and hit the gear icon next to Bloons Archipelago
8. Input all your server information, and click the connect button.
