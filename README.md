<h1 align="center">BloonsArchipelago</h1>

This Mod is for the [Archipelago Multiworld Randomizer](https://archipelago.gg).  It connects you to the AP server through the settings menu.

Currently in super early development, if you find any bugs please report them in the issues tab here for client issues, or in the [Bloons TD6 channel](https://discord.com/channels/731205301247803413/1465832575359516970) in the Archipelago discord.

## Requirements
1. [BTD6 Archipelago client](https://github.com/Matt41321/Archipelago/releases/latest)
2. [Melon Loader](https://melonwiki.xyz/)
3. [BTD6 Mod Helper](https://github.com/gurrenm3/BTD-Mod-Helper#readme)
4. [Epic Games Compat](https://github.com/GrahamKracker/BTD6EpicGamesModCompat/releases/latest) if playing on the Epic Games version

## General Notes
1. Before setting up for modding, if you are worried about your account getting flagged then it is suggested to have a separate Ninja Kiwi account for modding.

## Steam Setup
1. Install [Melon Loader](https://melonwiki.xyz/) 0.7.3 on Bloons TD6 (BTD6)
2. Open BTD6 WITHOUT any mods installed
3. Open your BTD6 folder and open the Mods folder
4. Put both [BTD6 Mod Helper](https://github.com/gurrenm3/BTD-Mod-Helper/releases/latest) and [Bloons Archipelago](https://github.com/Matt41321/BloonsArchipelago/releases/latest) into the Mods folder.
5. Open BTD6
6. Click the Mods Button, and hit the gear icon next to Bloons Archipelago
7. Input all your server information, and click the connect button.

## Epic Games Setup
1. Install [Melon Loader](https://melonwiki.xyz/) 0.7.3 on Bloons TD6 (BTD6)
2. Open BTD6 WITHOUT any mods installed
3. Open your BTD6 folder and open the Mods folder
4. Put both [BTD6 Mod Helper](https://github.com/gurrenm3/BTD-Mod-Helper/releases/latest) and [Bloons Archipelago](https://github.com/Matt41321/BloonsArchipelago/releases/latest) dll's into the Mods folder.
5. Put the [Epic Games Compat](https://github.com/GrahamKracker/BTD6EpicGamesModCompat/releases/latest) into the Plugins folder.
6. Open BTD6
7. Click the Mods Button, and hit the gear icon next to Bloons Archipelago
8. Input all your server information, and click the connect button.
